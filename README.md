# AutoDraftman

AutoDraftman is a bilingual product prototype for creating scientific figures
from text and optional visual references.

## Local development

```bash
npm install
npm run dev
```

The local site runs at `http://127.0.0.1:5173`.

## GitHub Pages

The `main` branch is built and published automatically to:

`https://qcytsn.github.io/autodraftman/`

The Pages build uses `/autodraftman/` as its public base path. Local development
continues to use `/`, so the same source can move to a custom domain or another
host without changing product code.
